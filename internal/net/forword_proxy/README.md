# 高性能HTTP/HTTPS代理服务器

这是一个用Go语言编写的高性能HTTP/HTTPS代理服务器，支持以下特性：

## 主要特性

- ✅ **HTTP代理**: 支持标准HTTP代理协议
- ✅ **HTTPS隧道**: 支持HTTPS CONNECT隧道代理
- ✅ **MITM功能**: 支持中间人攻击模式，可拦截和分析HTTPS流量
- ✅ **连接池**: 内置连接池，提高性能和资源利用率
- ✅ **证书管理**: 自动生成和管理TLS证书
- ✅ **资源管理**: 完善的资源清理机制，避免内存泄漏
- ✅ **优雅关闭**: 支持优雅关闭，确保所有连接正确释放

## 快速开始

### 编译

```bash
cd proxy
go build -o proxy .
```

### 运行

```bash
# 基本运行
./proxy

# 指定监听地址
./proxy -addr :9999

# 启用详细日志
./proxy -v

# 指定证书文件
./proxy -cert mycert.pem -key mykey.pem
```

### 参数说明

- `-addr`: 代理服务器监听地址 (默认: `:8888`)
- `-cert`: TLS证书文件路径 (默认: `cert.pem`)
- `-key`: TLS私钥文件路径 (默认: `key.pem`)
- `-v`: 启用详细日志输出

## 使用方法

### 1. HTTP代理

配置浏览器或应用程序使用代理：
- 代理地址: `127.0.0.1`
- 代理端口: `8888` (或你指定的端口)

### 2. HTTPS代理

对于HTTPS网站，代理会自动处理CONNECT请求，建立隧道连接。

### 3. MITM模式

如果需要拦截和分析HTTPS流量，需要：

1. 将生成的CA证书 (`cert.pem`) 安装到系统或浏览器的受信任根证书中
2. 使用MITM代理模式

## 架构设计

### 核心组件

1. **Proxy**: 主代理服务器，处理HTTP和HTTPS请求
2. **CertManager**: 证书管理器，负责生成和缓存TLS证书
3. **ConnectionPool**: 连接池，管理到目标服务器的连接
4. **MITMProxy**: MITM代理，支持拦截HTTPS流量

### 资源管理

- 使用连接池复用连接，减少连接建立开销
- 自动清理过期连接，避免资源泄漏
- 支持优雅关闭，确保所有资源正确释放
- 使用context控制超时和取消操作

### 安全考虑

- 自动生成CA证书和服务器证书
- 支持证书缓存，提高性能
- MITM模式需要用户明确启用
- 建议在生产环境中验证服务器证书

## 性能特性

- 高并发处理能力
- 连接复用和池化
- 内存使用优化
- 自动资源清理

## 注意事项

1. **证书安装**: 使用MITM功能时，需要将CA证书安装到客户端
2. **安全风险**: MITM功能会拦截所有HTTPS流量，请谨慎使用
3. **性能调优**: 可以根据需要调整连接池大小和超时时间
4. **日志记录**: 详细日志模式会记录所有请求信息，注意隐私保护
